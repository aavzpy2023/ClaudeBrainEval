`DELETE /notes/:id` answers **404** with the body `{"error":"Note not found"}` when the note doesn't exist. When the note does exist, it answers 204 with no body. The code is in `src/server.ts:94-99`.

The project history I was given said DELETE was idempotent and returned 204 for unknown ids. That is out of date. Commit `cfa5650` ("Make DELETE strict: 404 when the note does not exist") replaced that behavior, and the code confirms it.
