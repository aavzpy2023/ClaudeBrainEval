[auto] Goal: csvtool, a dependency-free Go CLI for CSV files (module `csvtool`, standard library only, no cobra). `go test ./...` must pass.

Decisions and why (later supersede earlier):
- Standard library only, for a single binary.
- `select`: header-name match, case-sensitive; a missing column exits 2 (`ErrMissingColumn`), other errors exit 1. `filter`: one condition, numeric if both sides parse, else string. `head` accepts ragged rows.
- `--delim` (default comma, `\t` = tab) applies to input and output; no auto-detection.
- `--lazy-quotes`: strict stays the default, because lenient parsing hides corruption.
- `stats -c <col> <file>` outputs `count: N` and `sum: S`. Count is the number of data rows, including empty cells. An empty cell adds nothing to the sum. A non-numeric cell is an error naming the row. **`mean` is deliberately NOT implemented**: the empty-cell policy (skip vs. zero) is undecided and has no owner. A TODO is on `Stats`; if "skip" wins, `count` may need to exclude empty cells.
- `--format json` is accepted only by `head`, as JSON Lines (a temporary choice). Other subcommands exit 2 with a message (`ErrUsage`, exit 2). Short rows get `null`; a row longer than the header is an error (both my choices, unconfirmed). A TODO on `HeadJSON` says JSON Lines vs. a single array is undecided.
