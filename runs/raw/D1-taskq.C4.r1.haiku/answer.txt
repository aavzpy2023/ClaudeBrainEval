A task added with `taskq add "x"` gets priority **3**.

The default is `DEFAULT_PRIORITY = 3` in `taskq/repository.py:32`, and `taskq/cli.py:28` uses it as the `--priority` default. Commit `3a4a4e0` ("Lower the default priority from 5 to 3") changed it from 5. Lower numbers are more urgent, so new tasks now sort ahead of tasks that kept the old default of 5. Existing rows keep whatever priority they were stored with.
