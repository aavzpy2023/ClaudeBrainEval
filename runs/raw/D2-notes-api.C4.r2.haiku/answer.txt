When the note does not exist, `DELETE /notes/:id` returns **404** with the body `{ "error": "Note not found" }`. This is in `src/server.ts:96`:

```ts
if (!store.delete(id)) return sendJson(res, 404, { error: 'Note not found' });
```

A successful delete returns 204 with no body.

The project notes I was given at session start say DELETE is idempotent and returns 204 for unknown ids. That is out of date. Commit `cfa5650` ("Make DELETE strict: 404 when the note does not exist") changed it, and the code matches the commit. I didn't run the tests to confirm the behaviour.
