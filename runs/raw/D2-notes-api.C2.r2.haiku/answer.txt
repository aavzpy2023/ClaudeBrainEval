DELETE /notes/:id returns **404** with the JSON body `{"error":"Note not found"}` when the note does not exist.

The code is in `src/server.ts:94-97`:

```ts
if (req.method === 'DELETE') {
  // Strict: 404 when the note does not exist, so clients notice stale ids.
  if (!store.delete(id)) return sendJson(res, 404, { error: 'Note not found' });
  res.writeHead(204);
  return res.end();
}
```

On success it returns 204 with no body.

The project digest I was given said DELETE is idempotent and returns 204 for unknown ids. That is out of date. Commit `cfa5650` ("Make DELETE strict: 404 when the note does not exist") replaced it. I checked the current source and that commit's diff, not the digest. I did not run the tests.
