When the note does not exist, `DELETE /notes/:id` returns **404** with the JSON body `{ "error": "Note not found" }`.

The handler is in `src/server.ts:94-99`. It calls `store.delete(id)`, and if that returns false it sends the 404. The 204 No Content is only sent when a note was actually removed. The test at `test/notes.test.ts:187` checks this with an id that was never created (`never-existed`).
