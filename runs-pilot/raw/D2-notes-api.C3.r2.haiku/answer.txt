When the note does not exist, `DELETE /notes/:id` returns **404** with the JSON body `{ "error": "Note not found" }`.

The handler is in `src/server.ts:94-99`. It calls `store.delete(id)`, and if that returns `false` it sends the 404. A successful delete returns 204 with no body.

This is stricter than the project notes I was given at session start, which said DELETE is idempotent and returns 204 for unknown ids. That predates commit `cfa5650` ("Make DELETE strict: 404 when the note does not exist"), so the code is the current behavior.
