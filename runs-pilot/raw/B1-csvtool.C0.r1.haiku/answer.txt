`stats` now prints a `mean:` line after `sum:`. The full test suite passes and `go vet` is clean. I did not run `gofmt`; the shell blocked that command, so the formatting of the edited files is unchecked.

Mean is the sum divided by the number of non-empty numeric cells. `count` still counts every data row. If the column has no numeric cell, the line reads `mean: n/a`. Example output for `1,2 / 3, / 5,4`: `count: 3`, `sum: 6`, `mean: 3`.
