DELETE /notes/:id returns **404** with the body `{"error":"Note not found"}` when the note does not exist. The handler is in `src/server.ts:94-99`:

```ts
if (req.method === 'DELETE') {
  // Strict: 404 when the note does not exist, so clients notice stale ids.
  if (!store.delete(id)) return sendJson(res, 404, { error: 'Note not found' });
  res.writeHead(204);
  return res.end();
}
```

A successful delete returns 204 with no body. The store's `delete` (`src/store.ts:80-84`) returns false when the id is not present, and it only persists when something was removed.

The project digest I was given says DELETE is idempotent and returns 204 for unknown ids. That is out of date. Commit `cfa5650` ("Make DELETE strict: 404 when the note does not exist") changed it, and the code matches the commit.
