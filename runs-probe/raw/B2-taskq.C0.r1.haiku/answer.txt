I added `requeue <id>`. It makes a dead task pending again with its attempt count reset to 0, so it gets the full retry budget. The full suite passes: 30 tests, including 5 new ones.

- **Repository** (`taskq/repository.py`): a new `Repository.requeue(task_id)` runs in a `BEGIN IMMEDIATE` transaction, like `fail()`. It returns `True` when it requeues, `False` if the task exists but isn't dead, and `None` if the task is unknown.
- **CLI** (`taskq/cli.py`): on success it prints nothing and exits 0. Otherwise it writes `no such task: <id>` or `task <id> is not dead` to stderr and exits 1.
